## Как читать

Колонка «Проверка» говорит, чем кейс проверяется:

- **ядро** — автотест ядра (`cargo test --workspace`), в скобках файл с тестом;
- **интерфейс** — модульный тест интерфейса (`npm test` в `ui/`);
- **оболочка** — модульный тест приложения (`cargo test` в `crates/shell`, после `node prepare.mjs`);
- **e2e** — сквозной тест в браузере (`npm run e2e` в `ui/`), в скобках файл;
- **вручную** — пройден руками в браузере.

Колонка «Итог»:

- **пройден** — проверка есть и проходит;
- **не проверен** — функция есть, проверки не было;
- **нет функции** — в приложении этого ещё нет.

Правила для всех автотестов: агент только учебный (токены не тратятся); GitHub, GitLab и Docker заменены подставными программами, Linear — локальным сервером; push идёт в репозиторий во временной папке. Живые сервисы трогались только вручную и только на демо-репозитории.

| PL-01 | План, нарисованный руками | Шаг, вопрос и заметка добавляются, переименовываются, соединяются стрелками с подписями, разъединяются, удаляются; счёт и число в переключателе видов; после перезагрузки всё на месте | ядро (`plan.rs`); интерфейс (`plan.test`); e2e (`plan.spec`) | пройден |
